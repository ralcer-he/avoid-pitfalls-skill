# 模板：开发前检查

> 用法：开始新功能/新页面/新组件前，把下面这段连同任务描述发给 AI，或自己对照执行。

```
我在开发一个新功能：【粘贴功能描述】。开发前请按避坑指南执行「开发前检查」：

1. 设备/环境：功能涉及 Tauri（桌面）、Capacitor（移动）、Web 哪些端？移动端判断不要只用 CSS 断点（桌面窗口可能是窄屏手机比例会误判）
2. 移动端适配：顶部是否要留状态栏/安全区高度（Android 15+ edge-to-edge 强制）？有无输入框需要键盘适配（fixed bottom + 键盘高 CSS 变量，不用 setState）？
3. 权限：涉及麦克风/通知/存储/网络吗？按「manifest 声明 + 运行时主动请求」两步走，用户拒绝要有兜底
4. 颜色/图标：一律用 CSS 变量，SVG 图标，禁止 emoji；移动端输入控件字号 ≥16px
5. 状态管理：新 state/selector 是否引用稳定？避免闭包陷阱、并发初始化、selector 副作用
6. 数据：新增表/字段了吗？导出/清空/备份函数要同步覆盖；persist version 要提升
7. 打包影响：涉及版本号吗？列出所有需要同步的位置

请先读 references/避坑指南-通用版.md 对应章节，再给出你的实现方案，标注每个注意点的处理方式。
```
