# 模板：日志总结

> 用法：每轮开发收尾时，把下面这段发给 AI，生成更新日志 + 踩坑记录 + 交接要点。

```
本轮开发完成。请帮我做收尾总结：

1. 【更新日志 CHANGELOG】按「新增 / 修复 / 优化」分类，每项一句话，注明涉及文件
2. 【踩坑记录】列出本轮遇到的问题 + 解决方式 + 可推广的教训（格式：问题 → 解法 → 教训）
3. 【避坑指南补充】是否有值得补进避坑指南的新经验？有的话写出拟新增的条目（含所属章节）
4. 【交接要点】下一步该做什么、有什么注意事项，让下个会话（或换 AI）能无缝接手
5. 【版本标记】本轮是否有需要保留的版本标记日志（console.log）

输出为可直接粘贴进日志/交接文档的 Markdown。
```
