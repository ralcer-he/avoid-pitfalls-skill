# 模板：疑难 bug 排查

> 用法：遇到反复搞不定的 bug 时，把下面这段连同现象描述发给 AI。

```
遇到一个疑难 bug：【描述现象、触发条件、出现环境（机型/系统版本/输入法/浏览器）】。

请按避坑指南的「排查方法论」处理：

1. 先判断这是不是「环境/配置类问题」（输入法/键盘/打包/权限/网络）：
   - 是 → 先和「能正常工作的参照 app」逐项对比原生配置（viewport meta、capacitor.config.json、Keyboard 插件配置、windowSoftInputMode、targetSdk、AndroidManifest 权限），差异项优先怀疑，不要先在 Web 层反复改代码
2. 涉及输入法/键盘吗？检查有没有「多余的配置开关」（interactive-widget、captureInput 这类曾导致语音输入重复插入的元凶）
3. 涉及状态管理吗？检查 selector 引用稳定性、空数组/对象字面量、闭包捕获旧值、异步回调里读过期 state
4. 涉及数据吗？检查时区（toISOString 是 UTC）、持久化 version、导出/清空是否覆盖全部表
5. 一轮无效必须换思路（改代码 → 改配置 → 换参照对比），并明确记录哪些轮次是弯路

排查完请给出：根因、证据（配置/代码位置）、修复方案、以及这条经验是否值得补进避坑指南。
```
